# xnatctl documentation

These are the Sphinx sources. GitHub renders them only partially — Sphinx
roles like `:doc:` and `:class:` show up as raw text here.

**Read the rendered documentation at
[xnatctl.readthedocs.io](https://xnatctl.readthedocs.io/en/latest/).**

To build locally:

```bash
uv sync --extra docs
cd docs && make html
```
